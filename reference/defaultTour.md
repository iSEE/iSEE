# Define the default tour

Define the default tour for the subset of the Allen brain dataset. This
is only available when run on the `iSEE(sce)` example in
`?"`[`iSEE`](https://isee.github.io/iSEE/reference/iSEE.md)`"`.

## Usage

``` r
defaultTour()
```

## Value

A data.frame where each row is a tour step. The first column specifies
the UI element to be highlighted by the tour, while the second column
contains the tour text.
